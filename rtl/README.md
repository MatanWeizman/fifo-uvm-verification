# Boolean Algebra and Combinational Logic

## Overview
This section contains practical exercises in Boolean algebra and combinational logic using Verilog.

## Topics Covered
- Boolean algebra identities and simplification.
- De Morgan's laws.
- Truth tables and Boolean equivalence.
- Karnaugh maps and minimal Boolean expressions.
- Combinational logic implementation using Verilog.

## Implementation
Boolean functions are implemented using Verilog continuous assignments (`assign`). Simplified expressions are compared with their original forms to study logical equivalence.

## Verification
Testbenches will be added to check the implemented functions against their expected truth tables.
