# FIFO Verification Project

## Overview
This project aims to build a verification environment for a synchronous FIFO (First In, First Out) buffer.

## What Is a FIFO?
A FIFO is a digital data structure in which the first item written is the first item read. FIFOs are commonly used to temporarily store and transfer data between hardware blocks.

## Verification Goals
The project will aim to verify that:
- Data is read in the same order in which it was written.
- Data is preserved correctly during write and read operations.
- Empty and full conditions behave according to the specification.
- Reset initializes the FIFO to its expected state.
- Boundary conditions and invalid operations are handled correctly.
