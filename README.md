# FIFO UVM Verification

Verification project for a parameterized synchronous FIFO.

## Project Status

Currently learning Verilog and building the project from scratch.

## Goals

- Learn Verilog and RTL design
- Build a synchronous FIFO
- Build a SystemVerilog testbench
- Learn constrained-random verification
- Learn SystemVerilog Assertions
- Build a UVM verification environment
- Develop automated regression tests
